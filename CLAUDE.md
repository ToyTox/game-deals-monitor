# game-deals-monitor

Любая задача на изменение кода, тестов или документации выполняется через скил `dev-cycle` (`.claude/skills/dev-cycle/SKILL.md`): план → утверждение → реализация по плану → независимое ревью → повтор при замечаниях → текст коммита и описания PR (коммитит и оформляет PR пользователь сам). Вопросы, не требующие изменений, можно отвечать напрямую.
