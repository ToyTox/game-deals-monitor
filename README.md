# 🎮 Game Deals Monitor API

Полнофункциональное API приложение для мониторинга скидок и бесплатных игр на различных платформах: Steam, Epic Games, GOG и других.

## ✨ Возможности

- 🔍 Автоматический мониторинг платформ каждый день
- 💾 Сохранение истории цен для отслеживания изменений
- 🎯 Фильтрация и поиск по скидкам, платформам, названиям
- 📊 Статистика по скидкам и предложениям
- 🔄 Асинхронная обработка - все платформы проверяются параллельно
- 📈 REST API с полной документацией
- 🗄️ SQLite/PostgreSQL - подключите нужную БД
