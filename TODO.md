Чек-лист известных проблем и задач. Подробности по коду — в [документации](docs/).

## Баги

- [ ] **`EpicParser.parseFreeGames()` — пустая заглушка.** Метод содержит только комментарий и всегда возвращает пустой массив, так что еженедельные раздачи Epic не собираются.
- [ ] **Free-to-play игры считаются бесплатными.** `isFree` выставляется по `currentPrice === 0`, поэтому в `/api/games/free` вместе с раздачами попадают F2P-тайтлы витрины.

## Улучшения

- [ ] **Аутентификация для `/api/admin/*`.** Сейчас раздел ничем не защищён: любой, кто до него дотянется, может запустить парсинг и прочитать статистику.
- [ ] **Асинхронный `POST /api/admin/parse`.** Ответ ждёт завершения всех сетевых запросов; для полного прогона это десятки секунд.
- [ ] **N+1 в статистике.** `getStats()` в цикле по платформам делает по два `count`-запроса на каждую — линейно растёт по числу площадок.
- [ ] **Переезд на PostgreSQL для Docker.** `docker-compose.yml` передаёт PostgreSQL-строку подключения, а проект настроен на SQLite — см. [docs/docker.md](docs/docker.md).
- [ ] **`parsePlatform()` ищет парсер по подстроке в имени класса.** Совпадение по `constructor.name.includes(platform)` — хрупко; нужно точное сопоставление по `getAvailablePlatforms()`.
- [ ] **`LOG_LEVEL` объявлена в `.env.example`, но в коде не используется.**

## Ограничения by design

- **Цены разных площадок в разных валютах.** Steam заполняет `Game.currency` по коду региона (по умолчанию RUB), Epic и GOG — USD. Сравнивать абсолютные цены между площадками нельзя; корректны только скидки в процентах (`topDiscounts`, `averageDiscount`).
- **Второй источник Steam — HTML.** Список акций из `/search/results/` разбирается через cheerio по классам вёрстки. Если Valve поменяет разметку, источник тихо вернёт 0 игр — витрина при этом продолжит работать. Отключается через `STEAM_SEARCH_PAGES=0`.
